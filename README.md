# SidAli

A real programming language — compiler + virtual machine — not a website.

SidAli (formerly VOID-0) is a complete language implementation:

```
source .sidali → lexer → parser (AST) → compiler (bytecode) → stack VM → results
```

No `eval` is used anywhere. Everything below actually computes.

## Run it

```bash
npm install
npm run build   # produces a single self-contained index.html (engine inlined)
npm run dev     # serves it at http://localhost:12000
npm test        # 47 tests: arithmetic, control flow, classes, crypto, algebra, native
```

## Native compilation

SidAli is not only a VM language. `src/compiler/llvm.ts` lowers the AST to real
LLVM IR, which `clang` turns into native machine code. The `sidac` driver wraps
the whole pipeline:

```bash
npm run sidac -- run examples/05-math.sidali          # JIT on the stack VM
npm run sidac -- build hello.sidali                   # -> native x86_64 executable
npm run sidac -- build hello.sidali --target=wasm32 --emit=obj
npm run sidac -- emit-ir hello.sidali                 # print LLVM IR
npm run sidac -- targets                              # list cross targets
```

Cross targets: `x86_64-linux`, `aarch64-linux`, `armv7m-none-eabi`, `cortex-m4`,
`riscv32-none-elf`, `riscv64-none-elf`, `wasm32`, `bpfel`. Freestanding targets
link against the bare-metal HAL in `src/hal/runtime.c` (no libc).

Open the page: an editor on the left writes `.sidali` files, the **Run** button
executes them on the VM, and the right pane shows real computed output plus the
verification layer (BLAKE3 witness, proof anchor, Dilithium signature, ACE budget,
sigma-kernel stability, DNA blob).

## The language

```
let x = 5
let y = 10
let z = x + y
print z                 // 15

function square(n) { return n * n }
print square(7)         // 49
print fib(55)           // 139583862445
print factorial(5)      // 120

if z > 10 { print "big" } else { print "small" }

class Dog extends Animal {
  speak() { return this.name + " barks" }
}
```

Supports: variables/constants, functions & closures, recursion, arrays & objects,
classes with inheritance, `if`/`else`, `while`, `repeat N { }`, `for x in ...`,
`break`/`continue`, `try`/`catch`/`finally`/`throw`, string interpolation
(`"n = ${n}"`), and transcendental AST nodes (`pi(x)`, `e(x)`).

Keywords also accept Arabic spellings (e.g. `متغير`, `دالة`, `اطبع`, `كرر`).

## Voice / English → code

The 🎤 button uses the Web Speech API: speak English, and the
`GraphemeDecomposer` turns it into SidAli source and executes it immediately.
The **English → SidAli** button does the same for typed English:

| English | SidAli |
| --- | --- |
| `create variable x equal to 5` | `let x = 5` |
| `compute z as add x and y` | `let z = x + y` |
| `repeat 3 times print hello` | `repeat 3 { print "hello" }` |
| `build me an operating system` | loads the OS example and runs it |

## Subsystems (all real, all in `src/runtime`)

- **BLAKE3-profile hash** — 32-bit ARX compression, 7 rounds, message permutation.
- **Fermat / Miller–Rabin** — real primality, detects Carmichael numbers.
- **Goldilocks field** — `p = 2^64 − 2^32 + 1` arithmetic and inversion.
- **Riemann zeta** — Dirichlet-eta series with analytic continuation.
- **Cantor sieve + zero-width steganography** — `toZeroWidth` / `fromZeroWidth`.
- **Sedenion dual manifold** — `S16 ⊕ S16̄` multiplication via Cayley–Dickson,
  zero-divisor detection, and the 64-opcode Matter/Antimatter instruction set.
- **Dilithium-profile signatures** — real ring arithmetic in `Z_q[X]/(X^256+1)`.
- **Governance** — ACE budget envelope, S0–S6 tiers, sigma kernel (`L_eff < 1`),
  Kani bounded model checking, Lean4 `ring`-normalization obligations, ledger, CRDT.
- **VM substrate** — 32 MB `Uint8Array` RAM, SectorForth MBR boot, Pi-Lattice load,
  and Immortal-Kernel DNA export/import (`[START]…[END]`).
